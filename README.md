# Что делает бот?

Отвечает на команды вызова, меню, и повторяет обычное сообщение пользователя

# Как запустить бота?

1. pip install -r requirements.txt
2. Создать .env по образцу
3. python main.py

# Доступные команды для пользователя

1. /start - запуск бота
2. /menu - вызов inline меню с выбором
